# HISTORICAL ARCHIVE

Здесь лежат аудиты ранних версий (v1.2–v1.3, KERNFS). Они сохранены как
доказательная история: каждый отчёт фиксировал, что было заявлено и что
проверено на тот момент. **Они не описывают текущее состояние.**

Актуально:

- `README.md` — витрина;
- `docs/METRICS.md` — блок `CURRENT STATE` + append-only журнал;
- `docs/CAPABILITY_STATUS.md` — журнал дефектов #1–#239.
