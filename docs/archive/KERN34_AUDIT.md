## 🔴 АТАКА 1: Шлюз Истины обходится **ОДНИМ БАЙТОМ**

Заявление: *«ИИ не имеет права устанавливать статусы T или F»*, *«e=1 только если внешний прувер (а не ИИ) вернул .Proved»*.

Код `runTrustedChecker` читает вердикт **из полезной нагрузки сертификата**:

```zig
const magic = payload[0];          // <-- ЭТО БАЙТ, ПРИСЛАННЫЙ ИИ
if (magic == 0xAA) return .Proved; // <-- ИИ управляет вердиктом
```

Демонстрация (`src/attack.zig`) — ИИ **не предоставил доказательства**, просто
положил байт `0xAA`:

```
########## АТАКА 1: ИИ присылает ОДИН БАЙТ вместо доказательства ##########
Вердикт: T, e=1
>>> ИТОГ: код ДОПУЩЕН в прод БЕЗ ЕДИНОГО ДОКАЗАТЕЛЬСТВА <<<
```

**«Доверенный прувер» доверяет недоверенному входу.** Защита от галлюцинаций
не работает: достаточно угадать один байт (он же прямо описан в исходнике).

Тесты CONF-30.4 проверяют только **длину** (< 8) и **совпадение хешей** — сам
вердикт подделывается беспрепятственно.

## 🔴 АТАКА 2: KERNFS не находит **ни одного** файла

```
-- /raw/src/core/memory.zig --                              ошибка: FileNotFound
-- /claims/claims/L0_AlignmentInvariant.kern/status --      ошибка: FileNotFound
-- /claims/L0_AlignmentInvariant.kern/status --             ошибка: FileNotFound
```

Причина — **Фаза 1 и Фаза 3 несовместимы**:

| Требует роутер | Что в золотом векторе |
|:--|:--|
| `/raw/` → объект **type 0x0002** с путём | объект **type 0x0001** (manifest) |
| `/claims/` → объект **type 0x0005** с путём | `logical_path_offset = 0xFFFFFFFF` — **пути нет** |
| пул строк в `data_payload_offset` | там **JSON-манифест**, а не пул строк |
| `payload_offset` **абсолютный** | **относительный** = 0 |

**Совпадений быть не может ни при каком пути.** «Семантический проектор» не
проецирует ничего.

## 🔴 `check-integrity` **падает** на повреждённых файлах

Команда, чья задача — проверка целостности, не умеет сообщить о нарушении:

| Вход | Код | Что вместо отчёта |
|:--|--:|:--|
| битый magic | 1 | `error: BadMagic` + стек (не сообщение) |
| обрезан до 50 байт | **134** | `panic: index out of bounds: index 128, len 50` |
| пустой файл | **134** | `panic: reached unreachable code` |

`KimgHeader.parse` корректно возвращает ошибки, но `main.zig` использует `try`
без обработки → паника вместо «образ невалиден».

## 🔴 Три команды — **декорация**

| Команда | Заявлено | Факт |
|:--|:--|:--|
| `verify` | «прогон сертификатов через Admission Gate» | сертификат **зашит в код**; образ **не читается** |
| `ls` / `cat` | «Подключаем виртуальную ФС из фазы 3» | **заглушка**: печатает «используйте API», не монтирует |
| `report` | «генерация канонического манифеста» | пишет **зашитый текст**: «**Статус: 99% VERIFIED (e=1)**» — образ не читается |

**`report` заявляет «99% VERIFIED (e=1)» для любого файла**, включая пустой.
Это фабрикация результата проверки.
