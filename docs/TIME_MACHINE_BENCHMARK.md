# TIME MACHINE BENCHMARK — эквивалентность переписывания, измеренная

**Идея.** Человек или ИИ-агент переписал функцию «почище». Тесты зелёные. Вопрос: **поведение
то же?** Закон писать не надо — он универсален:

```
∀x: f_old(x) == f_new(x)
```

Вот что измерено сегодня, одной командой.

## Команда

```bash
python3 tools/migration_bench.py                     # встроенные пары
python3 tools/migration_bench.py old.py new.py       # своя пара
```

Вывод (дословно):

```
вердикт          кейс                                       detail
ЭКВИВАЛЕНТНО     чистая переписка clamp                     [EQUIVALENT] clamp_value: рефакторинг
                                                            математически эквивалентен на всём домене Z
РАСХОЖДЕНИЕ      переписка с переставленными границами      [DIVERGED] clamp_value: РЕФАКТОРИНГ ИЗМЕНИЛ ПОВЕДЕНИЕ
```

Контрпример для второй пары (печатается инструментом и проверен в `python3`):

```
[КОНТРПРИМЕР] lo = 1, hi = -1, x = 0:  res_old = 1, res_new = -1
python3:        old = 1 | new = -1 | расходятся: True
```

**Почему это ценно:** на нормальном домене (`lo < hi`) обе версии совпадают, юнит-тесты молчат.
Расхождение живёт на **вывернутых границах** — ровно тот класс, который агент не проверяет, а
человек не замечает в диффе.

## Граница, измеренная на живом примере

Первая версия стенда использовала «скидку» `amount * rate` и получила:

```
[!] нет одноимённых функций в подмножестве — сравнивать нечего
    причины: apply_discount: нелинейное умножение
```

То есть `--diff-equiv` покрывает **границы, пороги, ветвления, сравнения, `div`/`mod` на константу**,
но не произведения двух переменных. Стенд печатает такое как `НЕ СРАВНИМО` — а не «эквивалентно».

## Что нужно, чтобы прогнать четыре эксперимента из плана

| Эксперимент | Что требуется от нас | Состояние |
|:--|:--|:--|
| 1. Слепой аудит реальных `refactor`-коммитов | клон с историей (`git clone` без `--depth`), извлечение BEFORE/AFTER в два файла, запуск стенда | **не сделано**: в этой сессии репозитории качались tarball-ом без истории |
| 2. Взлом IAM/RBAC через Белнапа | перевод JSON-политик в SMT + `JOIN_K(T,F)=B`; у нас есть `[B] КОНФЛИКТ` на KERN.md, но не на IAM | **не сделано**, нужен маппер политики → формулы |
| 3. RLVR против «читерства» | 30 задач + агент; у нас есть `--anti-cheat`, `contracts.lock`, `rlvr_oracle_check.sh` | **не сделано**: нужен прогон с живой моделью (в сессии модели падали по таймауту) |
| 4. DeFi-округление (`no_arbitrage`) | функция AMM + закон «дробление не даёт больше» | **есть демо** в `no_arbitrage` (найден эксплойт дробления `a1=100, a2=1`), но не на реальном контракте из аудита |

## Честный итог

- **Работает и измерено:** эквивалентность переписывания — `ЭКВИВАЛЕНТНО` с сертификатом или
  `РАСХОЖДЕНИЕ` с конкретным входом, без единой аннотации от человека.
- **Не сделано:** реальные исторические коммиты, IAM-политики, прогон с живой моделью, аудит
  реального DeFi-контракта. Каждый пункт требует данных, которых в этой сессии не было.
- **Не обещаем:** «найдёт любой сломанный рефакторинг». Нелинейная арифметика — вне подмножества,
  и стенд говорит это вслух.
