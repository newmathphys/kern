**ЗАЧЕМ ЭТОТ ФАЙЛ.** «Десятки примеров на каждую возможность» — не выдумка: они
**уже лежат в репозитории**. Здесь — ЧТО есть, СКОЛЬКО задач, **ЧЕМ подтверждается**
вердикт и **ЧЕГО это не доказывает**. Три колонки обязательны: строка без оракула
в таблицы 1–2 не попадает.

**ПРАВИЛО ОРАКУЛА.** Оракул — это **внешний** арбитр, которого нельзя подделать
нашим же кодом: живой компилятор (`gcc`/`rustc`/`zig`), живой интерпретатор
(`python3`), либо официальная разметка (`:status`, `expected_verdict`).
**Модель, проверенная против модели, — это вакуум**, и такие строки вынесены
в раздел 4 с явной пометкой.

## 3. Чего эти корпуса НЕ доказывают

| Утверждение, которого НЕЛЬЗЯ делать | Почему |
|:--|:--|
| «KERN находит все баги в репозитории» | измерено: **0 из 715** функций чужих репозиториев попадает в подмножество |
| «Найдены CVE» | `catalan`/`lcm`/`binom` — **учебные** репозитории; новых CVE не найдено ни одного |
| «MBPP+ слепое пятно = уязвимость» | это **необработанный краевой случай** в коде ИИ, а не эксплуатируемая уязвимость |
| «40/40 QuixBugs — формальное доказательство» | это **живой дифференциальный реплей**; формально (SMT) решено **6 из 40** |
| «SAFE-задача доказана» | в SV-COMP проверяется **отсутствие сигнала на перебранных свидетелях**, а не недостижимость |

## 4. Модельные семейства: оракул пока только внутренний (граница названа)

Шесть семейств проверяются **против модели**, а не против реальности. Публиковать
их примеры как «доказательства» **нельзя** — до появления физического оракула
(шаг D плана) они идут с этой пометкой.

| Семья | Состояние оракула |
|:--|:--|
| `chc` (инварианты циклов) | нужен **конкретный прогон** цикла с проверкой инварианта на каждой итерации |
| `dtmc` (вероятности) | нужно **Монте-Карло** против аналитической `P` |
| `redos` | нужен **секундомер** на патологической строке |
| `absint` | нужно **сравнение интервала с конкретными значениями** |
| `string` (QF_S) | нужна **реальная попытка открыть файл** вне корня |
| `noninterference` | останется **шумным статистическим** оракулом — так и будет помечен |
