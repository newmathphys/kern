### 2. Monocypher `src/monocypher.c`: `fe_cswap` / `fe_ccopy` — `-b`

```c
static void fe_cswap(fe f, fe g, int b) { ... b = -b; ... }
```

`b` — это **маска константного времени**: приходит из сравнений вида
`crypto_verify32(...)` и принимает ровно `{0, -1}`. Переполнение `-(-1) = 1`
невозможно, `INT_MIN` в эту функцию не попадает.
**Классификация: скрытое предусловие (hint), НЕ баг.** Тип `int` вместо
`{0,-1}`-диапазона — это цена того, что анализатор не выводит диапазон из
`crypto_verify*`; честнее было бы назвать это «предусловие `b ∈ {0,-1}` не выписано».

### 4. yajl `src/yajl_tree.c`: `handle_number`, размер в `malloc()`

`[OVERFLOW PATH]` на `malloc(strlen(...) + ...)`. Переполнение требует строки
длины ~`SIZE_MAX`, то есть недостижимо: `yajl` принимает числа из уже разобранного

## ВЕРДИКТ ПО НАХОДКЕ №9 (`yajl/src/yajl_tree.c` → `handle_number`): hint, НЕ уязвимость

Проверено по исходнику `lloyd/yajl` @ `5e3a785` (типы по всей цепочке, а не «на глаз»):

```c
/* src/yajl_tree.c:292 */
static int handle_number (void *ctx, const char *string, size_t string_length)
{
    v->u.number.r = malloc(string_length + 1);      /* :301 */
```
```c
/* src/api/yajl_parse.h:81 — тип колбэка, через который приходит длина */
int (* yajl_number)(void * ctx, const char * numberVal, size_t numberLen);
```
```c
/* src/yajl_parser.c:191,282 — источник значения */
size_t bufLen;
... hand->callbacks->yajl_number(hand->ctx, (const char *) buf, bufLen);
```

**Цепочка `size_t` → `size_t` → `size_t`, ни одного 32-битного каста.** Значит
`string_length + 1` переполняется только при `string_length == SIZE_MAX`
(16 ЭБ = 2⁶⁴−1), а не на 2–4 ГБ: класс `CVE-2023-33460`/`INT_MAX+1` здесь **не
воспроизводится**. Гипотеза «длина хранится в 32-битном `unsigned int`/`int`»
проверена и **опровергнута** чтением кода, а не рассуждением.

Остаточная формулировка честная: это **скрытое предусловие** — `yajl` обрабатывает
число из уже разобранного буфера, чья длина ограничена памятью вызывающего;
переполнение размера требует входа размером с адресное пространство. Статуса
«баг yajl» не присваиваю.

### Что это даёт методике

Находки вида «размер в `malloc()`» нужно проверять **по типу аргумента на каждом
шаге** (сигнатура → колбэк → источник), и только при наличии 32-битного каста
квалифицировать как `INT_MAX+1`-класс. Один `grep` по трём файлам заменяет
часовую дискуссию — и в этом случае спас от ложного upstream-репорта.
