KERN playground

Настоящее ядро в WebAssembly: wasm32-freestanding, без WASI, без сисколлов, статическая арена 4 МБ. Всё считается в вашем браузере, офлайн.

Сверка бинарника (не верьте подписи — посчитайте сами)

Загружаю kernc.wasm…

1. Логика Белнапа: конфликт не схлопывается

Разрешение (T) ⊔ запрет (F) = B — «и да, и нет» (HTTP 409), а не «deny побеждает».

—

2. Код Хэмминга: допуск с исправлением ошибки

64-битный AdmissionCode; меняйте биты и смотрите, что вердикт держится.

—

3. Решатель Фурье–Моцкина: две линейные системы

Совместны ли a1·x ≤ b1·y + c1 и a2·x ≤ b2·y + c2? Решает ядро, не JS.

—

4. verifyProof: перепроверка Z3-сертификата в памяти

Байты кладутся в отдельный входной буфер (kern_wasm_input_ptr / kern_wasm_input_cap), чтобы аллокатор арены не затёр вход во время проверки. Эталон: abs.c, 16 шагов proof-DAG, снят с живого Z3.
