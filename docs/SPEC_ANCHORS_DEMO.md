# Демонстрация архитектурного моста «текст → контракт»

Этот файл показывает, как фраза из документации получает статус **`e=1`**
(ДОКАЗАНО), а не остаётся просто текстом.

## Как это работает

Свободный текст доказать нельзя — это буквы. Поэтому рядом с фразой ставится
**машинный якорь**, ссылающийся на контракт (`.smt2`) или свидетельство
исполнения (`.jsonl`):

```html
<!-- @kern:spec path="formal/gate_mask.smt2" -->
Текст утверждения.
```

Сканер `tools/scan_to_kern.py` извлекает якорь и связывает фразу с контрактом.
`kernc build` кладёт контракт в образ `.kimg`. `kernc verify` находит его и
**прогоняет через Z3**: `unsat` → `e=1`, `sat` → `e=0` (контрпример).

## Утверждение 1 (есть контракт → ДОКАЗУЕМО)

<!-- @kern:spec path="formal/gate_mask.smt2" claim="Врата: checker_id >= 32 не получает прав checker 0" -->
Врата Истины не позволяют недоверенному чекеру с `checker_id >= 32` получить
права чекера 0 (заворот маски исключён).

**Почему доказуемо:** это утверждение о **логике битовой маски**, а не о
физической величине. Z3 проверяет его на ВСЕЙ области значений (2³² комбинаций),
а не на выбранных примерах.

---

## Утверждение 2 (нет контракта → НЕ доказуемо)

<!-- @kern:evidence path="docs/evidence/humaneval_eval_results.json" claim="HumanEval+ зафиксирован официальным харнессом" -->
Результат HumanEval+ получен официальным харнессом EvalPlus.

**Почему это другой класс:** здесь утверждение о **факте исполнения**, а не о
математическом свойстве. Его нельзя доказать формулой — только приложить
**свидетельство** (лог запуска с кодом возврата и хэшем). Якорь `@kern:evidence`
именно это и делает.

---

## Итог

| Тип утверждения | Якорь | Чем подтверждается | Статус |
|:--|:--|:--|:--|
| Математическое свойство | `@kern:spec` → `.smt2` | вердикт Z3 (unsat) | `e=1` |
| Факт исполнения | `@kern:evidence` → `.jsonl` | лог запуска + хэш | `admitted` |
| Просто текст | (нет) | ничем | `e=0` |

**Ключевой принцип:** сканер НЕ пытается понимать смысл фразы — иначе строгий
верификатор превратился бы в ненадёжную языковую модель. Он лишь **связывает**
текст с контрактом, а истину устанавливает решатель.
