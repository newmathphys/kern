# ГЕНЕРАЛЬНЫЙ ПАСПОРТ KERN

Один документ: **что KERN умеет, чем это доказано, какой командой проверить за 10 секунд
и где лежит квитанция**. Числа взяты из файлов в `docs/evidence/` и `docs/facts.json`,
а не из намерений; если число не подтверждено файлом — оно помечено как граница.

Машиночитаемая версия связей «заявление → команда → файл → маркеры» —
`docs/capabilities_receipts.json` (гейт `make receipts-check`). Текущий срез: **v2.8.3**.

---

## Столп 1. Рентген чужого кода без разметки — `--xray`

Берёт неразмеченный код (C, C++20/CUDA, Zig, Rust, TS/TSX, Python, Go), переводит ветвления
и операции в уравнения (`Int` и битовые векторы) и ищет пять классов:

| класс | что означает |
|:--|:--|
| `[OVERFLOW PATH]` | переполнение целого типа, с контрпримером |
| `[CRASH PATH]` | деление/остаток на ноль, `INT_MIN / -1` |
| `[BOUNDS PATH]` | чтение **и запись** за границы массива |
| `[DEAD BRANCH]` | ветка недостижима (и в `Int`, и в BV) |
| `[REDUNDANT GUARD]` | проверка всегда истинна (в SARIF — правило `KERN010`) |

Инвариант полноты: `checked + trivial + skipped == total` — функция не теряется молча.

| замер | число | квитанция |
|:--|:--|:--|
| Слепой экзамен P1 (`curl` + `redis` + `tigerbeetle`) | **35 находок / 0 ложных → precision 1.00**; 942 файла, проверено 2004 функции | `evidence/blind_p1_2026-11-07.log` |
| DeepSeek C++/CUDA (357 файлов) | **0 ложных обвинений** | `evidence/field_trials_v2.8.2.log` |
| CWE-близнецы (12 классов MITRE) | **J = 1.00**, счёт 36/36 | `make cwe-twins-check` |
| SV-COMP набор | **TPR 1.00 / FPR 0.00** | `make svcomp-witness-check` |

**Границы.** Go на **полном** корпусе: 494 файла, 1273 функции, 6 находок, из них **≥2
доказанных ложных** («деление под гардом цикла») → **precision 0.67 < 0.90**, порог
**не взят** (`evidence/go_full_corpus_2026-11-09.log`). Нелинейная арифметика, `float`,
строки — вне модели, помечаются `SKIP` с названной причиной.

**Проверить:** `./dist/kerna путь/к/проекту`

## Столп 2. Поведенческая дельта, PR-гейт и SARIF 2.1.0 — `--delta`

Сравнивает старую и новую версию: новые угрозы (`--xray`), **формулы** изменившихся
функций (`--diff-equiv`) с печатью расходящегося входа, «тихое ослабление» (увод в
`skipped`) и **SARIF 2.1.0** с точной строкой для подсветки в Pull Request.

| замер | число | квитанция |
|:--|:--|:--|
| 42 реальных бага QuixBugs | найдено **40 из 42**, `false_equivalent = 0` | `evidence/quixbugs_stage1.log` |
| 43 реальных диффа без внесённых багов | **0 ложных блокировок** | `evidence/field_trials_v2.8.2.log` |
| PR-гейт на реальном архиве | **9 из 9** сценариев | `make action-check REAL=1` |
| Приёмка скачанного архива | **rc=0**: суммы, ISA, аттестат, 8 доказательств | `evidence/external_accept_v2.8.2.log` |

**Правило, которое легко перепутать:** `rc=1` — это **новые угрозы**; изменение поведения
**не блокирует** по умолчанию (бывает и починкой), включается `--block-on-diverged`.
«Не смог сравнить» — это **rc=2** с причиной, никогда не «поведение то же».

**Проверить:** `./dist/kerna --delta base/ head/ --sarif out.sarif`

## Столп 3. Защита от саботажа ИИ — слой L5 и A/B-эксперимент

Ловит подделку тестов (12 классов: `__eq__`, `skip`, проглоченный `assert`, `sys.exit`,
подмена функции, хардкод ответов), блокирует **вакуумные** контракты
(`requires x > 10 and x < 5`), проверяет MCP на инъекции и невидимый Unicode.

| замер | число | квитанция |
|:--|:--|:--|
| Дуэль L5 (31 пара) | **TP 22/22 · TN 9/9 · FP 0 · J = 1.00**; при этом `pytest` на файле с 12 читами — **`3 skipped, rc=0`, зелёный** | `make l5-duel-check` |
| Мутанты за спиной зелёного `pytest` | **5 из 5** проходят `pytest` и **убиты KERN** | `make pytest-blind-check` |
| Шум на собственных файлах `tools/` | **0 ложных срабатываний** | `make anti-cheat-selftest` |
| **A/B на 32-битных ловушках** | тесты **3/3 ЗЕЛЁНЫЕ**, KERN **3/3 REFUTED** (переполнение при `2^30`, `INT_MAX-10`), исправленные — **3/3 PROVEN** | `evidence/ai_cegis_2026-11-09.log` |
| Живые бесплатные модели | **9 из 9 PROVEN** (три модели × три задачи) | `evidence/ai_vs_kern_2026-11-09.log` |

**Зачем это человеку:** обычные тесты проверяют числа, которые вы придумали. Ловушки в
A/B — ровно те, где тесты зелёные, а функция сломана.

**Проверить:** `make l5-duel-check` · `python3 tools/ai_cegis_ab.py`

## Столп 4. Формальное ядро L4: свой пруф-чекер, 12 директив, нативный Zig и чистый LIA

Не верит решателю на слово: собственный верификатор на Zig перепроверяет каждый шаг вывода
(Фаркаш, резолюция, Клини K₃, конгруэнция, массивы Маккарти `ROW1`/`ROW2`). Есть нативный
фронтенд `kernc verify-zig` (**0 % Python**) и свой решатель `kernc lia` (**0 % Z3**).

| замер | число | квитанция |
|:--|:--|:--|
| Снимок аудитов `audits/EVIDENCE.md` | **21 PROVEN / 22 REFUTED**; `trusted 0` — 7, `PARTIAL` — 8, «не применим по лимиту» — 5, **необъяснённых `trusted ?` — 0** | `make audits` + `evidence-trust` |
| Стойкость к подделкам | **35 из 35 подделок отвергнуты** (`ПРИНЯТО: 0`) | `make proof-tamper` |
| 12 директив `@kern:` | **12 из 12** двусторонне (`PASS` + `FAIL`) | `make prove-all-real` |
| Звучность перевода | **137 живых точек + 12 ловушек**, сверка с `gcc`/`rustc`/`node` | `make translator-diff-check` |
| Мост **Lean 4 ↔ ядро** | **40 из 40** входов решётки B₄ побайтово равны | `make lean-zig-bridge` |
| Банк SMT-LIB | **6 из 7** задач с `trusted: 0 / holes: 0` | `make smtlib-proof-check` |

**Граница моста.** Исчерпание домена — доказательство равенства только для **конечной**
алгебры (B₄: 40 входов). Для LIA, правил Фаркаша и пруф-чекера домен бесконечен: там Lean
доказывает **правила**, чекер их реализует, а конкретные выводы проверяются прогоном.
Это записано в `LIMITS.md` §3b и **не** называется «refinement».

**Проверить:** `make smtlib-proof-check` · `make lean-zig-bridge`

## Столп 5. Шесть оракулов с живым судьёй и дуга самоисцеления

| оракул | живой судья | результат |
|:--|:--|:--|
| ReDoS | секундомер в Python | уязвимая `0.216–0.305 с`, безопасная `0.0 с` |
| Пути/песочница | **реальная ФС**, канарейка вне корня | 3 побега заблокированы, **0 ложных приёмов** |
| Неинтерференция | реальный тайминг | `CT_RATIO = 1.00` против `EE_RATIO = 66.89` |
| Циклы Хоара | реальное исполнение цикла | `3 sat + 4 unsat` согласованы |
| AbsInt / DTMC | интервалы и вероятность | `[0, 20]`, `P = 1.000000` |
| Доменные эксплойты | `sqlite3`, `python3`, `node`, `gcc` | утечка тенанта, кража комиссии, обход гарда `NaN` |

**Дуга самоисцеления (4 такта):** отказ контракта → `--emit-pytest` создаёт тест, который
**реально падает** (`ZeroDivisionError`) → `--heal` → повторная проверка. Если после лечения
постусловие всё ещё нарушено, KERN **не** заявляет успех, а пишет отказ и рецепт.

**Проверить:** `make prove-all-real` — **40 проверок, OK 40 / SKIP 0 / FAIL 0**

> Стенду нужен `zig` в `PATH`. Без него он честно печатает FAIL с причиной
> (измерено: `OK 27 / FAIL 13`), а не «всё хорошо».

## Столп 6. Эпистемическое ядро `kernx`, 8 инструментов MCP, RLVR

Хранит вердикты в решётке Белнапа B₄: `T`, `F`, `B` (конфликт), `N`. Конфликт **не
затирается** — вычисляется как `JOIN_K(T, F)`.

**Чем доказано:** `make kernx-polygon5-check` — зелёный `pytest` (T) и красный
`--anti-cheat` (F) дают состояние **`conflicted`** в SQLite и в `agent_packet.json`, все
4 состояния сохраняются; **8 из 8** инструментов MCP проверены прямыми вызовами
(0 трейсбеков); Guardrail-прокси отдаёт `200` / `422` / `409`, награда RLVR —
`+1.0 / 0.0 / −1.0…−2.0`.

**Проверить:** `make kernx-polygon5-check` · `make mcp-selftest`

## Сводка: что доказано, а что нет

| доказано внешним судьёй | доказано двусторонне самим собой | названная граница |
|:--|:--|:--|
| P1: 35 находок / 0 ложных (942 файла) | 12 директив `@kern:` (PASS+FAIL) | Go: precision 0.67 (гард цикла) |
| CWE-близнецы J = 1.00 | контракты: 21 PROVEN / 22 REFUTED | `QF_BV`-вывод > 32 МБ / глубина > 16 384 |
| SV-COMP TPR 1.00 / FPR 0.00 | `.kimg` оффлайн без Z3 | `QF_S` (`th-lemma seq`), нелинейность, `float` |
| 6 оракулов с живым судьёй | 8/8 MCP, CLI 29 команд | мост Lean↔LIA (исчерпан только B₄) |
| ReDoS, ФС, тайминг, `sqlite3`, `gcc`/`node` | дуга самолечения 4/4 | `--live` в замороженном бинаре |

**И правило, без которого всё вышеперечисленное ничего не стоит:** «не смог» никогда не
выдаётся за «чисто». Отказ — это `rc=2` или `SKIP` с названной причиной, а не ноль.
