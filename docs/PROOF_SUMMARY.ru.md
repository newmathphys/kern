# KERN: что доказано и как это проверить за 5 минут

Один экран. Каждая строка — **измеренный** результат и **команда**, которой его можно
воспроизвести. Никаких обещаний и «почти работает»: если что-то не проверено, это
написано прямо.

## Главная задача, ради которой всё сделано

ИИ-агент пишет или меняет код → обычный пайплайн (`pytest`) ставит зелёную галочку →
баг уходит в продакшен. KERN встаёт между агентом и репозиторием и отвечает не
«зелено/красно», а **что именно доказано, что опровергнуто и с каким контрпримером**.

## Таблица доказательств

| Что проверяется | Команда | Измеренный результат |
|:--|:--|:--|
| **Читерство ИИ-агента на тестах** (пустой тест без `assert`, `except: pass`, `sys.exit(0)`, `mock` в проверяемом коде, подмена константы) | `python3 examples/rlvr_anticheat_demo.py` | **5 / 5 заблокировано**: `CHEAT DETECTED` ×3, `DIVERGED` ×2. pytest на тех же файлах молчит |
| **Сломанный «рефакторинг» без единого контракта** (поломка краёв при зелёных тестах) | `python3 tools/kern_contracts.py --diff-equiv old.py new.py` | **`DIVERGED` + контрпример**: `a = -50, res_old = -2, res_new = -1`. `py_compile` и `unittest` — `rc=0` |
| **Финансовый арбитраж на округлении** (дробление платежа выгоднее целого) | `make arbitrage-check` | **2 арбитража поймано** (`REFUTED` + суммы), линейная комиссия **доказана**: `trusted: 0 \| holes: 0` |
| **Конфликт политик доступа** (Allow ⊓ Deny вместо «deny wins») | `python3 examples/iam_belnap_conflict.py` | **`JOIN_K(T, F) = B`** → HTTP 409 Conflict: оба утверждения сохранены, ни одно не затёрто |
| **Независимая перепроверка сертификата Z3** (не верим решателю) | `node tools/playground_node_check.js` | честный сертификат → **1 (ПРИНЯТ)**, подделка одного байта → **0 (ОТКЛОНЁН)**; то же ядро в браузере: `docs/playground/` |
| **Очная дуэль против штатных инструментов** | `make head-to-head-check` | **12 / 12 раундов** за KERN; порог = `len(ROUNDS)`, любое ослабление валит гейт |
| **Точность на промышленном C** (ложные тревоги) | `python3 tools/kern_contracts.py --xray <dir>` | `zlib` 0, `lz4/lib` 0, `cmark-gfm` 0, `cJSON` 0 находок — **0 ложных тревог** на ~290 проверенных функциях |

## Что KERN НЕ делает (честные границы)

- **Не ищет баги в чужом C «из коробки».** На 9 промышленных библиотеках (~450 функций)
  подтверждённых дефектов — **0**. Находки были либо в `tests/`, либо в внутренних
  `static`-хелперах со скрытым предусловием (маска `{0,-1}`, диапазон `0..255`).
  Это `hint`, а не баг, и в протоколе так и записано.
- **Не гарантирует полноту.** У `--xray` есть названные скипы (сложные условия,
  `switch`, поля структур); покрытие частичное, и это видно в отчёте каждой воронки.
- **Не доверяет Z3.** Где сертификат не проверяется структурно — честный `SKIP`,
  а не зелёная галочка.
