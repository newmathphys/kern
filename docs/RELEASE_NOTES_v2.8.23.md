## Две ложные тревоги — в НАШЕМ классификаторе, обе сняты

- **`#621a` JS/TS:** `1/0 === Infinity` — это не краш. Класс `[CRASH PATH]` к `.js/.ts` больше
  не применяется, вместо находки печатается названная причина (проверено `node`).
- **`#621b` пустой диапазон:** если делитель — множитель границы итерации
  (`(0..rows * cols).map(|i| i / cols)`), то при `cols == 0` диапазон пуст и тело не выполняется.
  Проверено живым `rustc`: `neighbours(3, 0) -> []`, `exit=0`. Было 11 тревог, стало 0.
