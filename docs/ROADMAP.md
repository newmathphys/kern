## 7. Канонические правила Zig 0.17 std (проверено на этом репозитории)

> Источник истины: <https://ziglang.org/documentation/master/std/> (страница рендерится
> JS/WASM — сверяться с локальным `lib/std`). Ниже — только то, что **подтверждено
> компилятором** в этом репозитории.

| Правило | Как проверено |
|:--|:--|
| **Нет `@Type(...)` и `@ErrorSet`** — удалены в 0.17. Метапрограммирование типов: `enum(usize) { _ }` + `inline for` + `@enumFromInt` (паттерн `TypeRegistry`). | `error: invalid builtin function: '@Type'`; `TypeRegistry` компилируется, `of(u8)` для незарегистрированного типа даёт **ошибку компиляции** `Type not registered: u8`; два структурно одинаковых типа **различимы** (`A == B` → `false`) |
| `@intFromError(error.Foo)` — **работает** (дал `171`). | измерено |
| Коллекции: `std.ArrayListUnmanaged(T)` / `StringHashMapUnmanaged(V)` — `allocator` передаётся **явно** (`.append(allocator, …)`, `.deinit(allocator)`). | используется в ядре |
| Ввод-вывод и процессы — через `src/compat.zig`. Лимиты дочернего Z3: `std.os.linux.prlimit(pid, .FSIZE, &zero, null)` **после** `spawn` (у `std.process.spawn` в 0.17 **нет pre-exec хука**). | Эшелон 1, п. 8 (подтверждено SIGXFSZ) |
| Проверка памяти: `std.testing.checkAllAllocationFailures`, `std.testing.FailingAllocator`; в Фурье — Моцкине `@addWithOverflow` / `@mulWithOverflow`. | Эшелон 1, п. 1 |
| Константное время: `std.crypto.timing_safe.eql` для 32-байтных дайджестов; кодек `0x02` — `std.compress.flate`. | улучшение №5 |
| `catch null` в функции с `?T` — **ошибка**; нужно `catch return null`. `i2` — зарезервированное имя. | поймано компилятором при работе над QF_S |
