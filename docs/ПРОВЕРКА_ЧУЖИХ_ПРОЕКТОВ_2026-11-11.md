# Проверка чужих проектов из ветки r/opensource «Contributors wanted» (2026-11-11)

**Правило, по которому это делалось:** ничего не публикуем и не открываем заявок. Проверка идёт
локально, код скачивается в `/tmp` (не в `~/.cache` — диск бережём), и любой «дефект» обязан
подтвердиться **живым компилятором/рантаймом**, иначе он остаётся подсказкой.

## Метод

```bash
curl -sSL -o p.tgz https://codeload.github.com/<owner>/<repo>/tar.gz/HEAD
tar xzf p.tgz -C /tmp/p_<repo> --strip-components=1
KERN_DOMAIN_CLAMP=0:1000 python3 tools/kern_contracts.py --xray /tmp/p_<repo>
# далее ЛЮБАЯ находка проверяется: rustc / python3 / node / gcc -fsanitize
```

`KERN_DOMAIN_CLAMP=0:1000` сужает поиск контрпримеров до рабочего домена и **печатает** это
(одна строка на прогон), чтобы «находок 0» нельзя было прочитать как «код чист».

## Две ложные тревоги — **в моём инструменте**, а не в их коде

### 1. Делитель внутри пустого диапазона (`pencil-puzzles`, 11 × `CRASH PATH`)

Инструмент предупредил: `crates/core/src/grid.rs: neighbours: возможно деление на ноль: cols == 0`.
Код:

```rust
pub fn neighbours(rows: usize, cols: usize) -> Vec<Vec<usize>> {
    (0..rows * cols).map(|i| { let (r, c) = (i / cols, i % cols); /* … */ })
}
```

При `cols == 0` выражение `rows * cols` равно нулю, диапазон **пуст**, и тело замыкания не
выполняется ни разу. Проверено живым `rustc`:

```
cols=0 -> []
cols=2 -> [[0, 0], [0, 1], [1, 0], [1, 1]]
exit=0
```

**Вердикт: тревога ложная.** Класс дефекта инструмента: делитель, взятый из границы цикла,
диапазон которого пуст при нулевом делителе. Автору писать нечего — у него корректно.

### 2. Деление на ноль в JavaScript — не крах (`apogee`, 1 × `CRASH PATH`)

```
lib/summarize/mapReduce.js: pickFanIn: возможно деление на ноль: maxChunks == 0
```

В JS `1/0 === Infinity` (проверено `node`), исключения не будет. Плюс в самом коде есть контракт
в комментарии: «Caller guarantees partialCount > maxChunks». То есть это скрытое предусловие,
а не падение.

**Вердикт: тревога ложная** (класс «семантика деления зависит от языка»). Автору — в лучшем
случае заметка «предусловие стоит проверить в рантайме», не более.

## Что говорит это о самом KERN

Оба случая — реальные дефекты классификатора `--xray`, и они записаны, а не замазаны:

1. деление на границу **пустого** диапазона не может выполниться — нужен анализ достижимости
   тела цикла до того, как объявлять `[CRASH PATH]`;
2. в JS/Python деление на ноль не «краш» — `Infinity`/`ZeroDivisionError` это разные вещи,
   и класс должен называться по языку.

Пока это не исправлено, правило остаётся прежним: **`--xray` без закона — подсказчик**, и ни одна
его строка не идёт ни в отчёт мейнтейнеру, ни в Issue.
