## 3. Что сказал KERN

По каждому заявлению README KERN поставил статус **`empirical`** (самозаявление),
что в логике Белнапа = **`N` (не доказано)**:

```
$ kernc cat bk.kimg "/claims/README claims 'QA и вердикт' via pipeline_qa.py/status"
N
```

**Почему не `T`:** мы не запускали код проекта. Заявление «✅ проверено» — это
текст, а не прогон. Правило KERN: `e=1` только при машинной опоре.

## 4. Ручная проверка (чего KERN пока не делает сам)

Мы дополнительно сверили заявления LLM с файловой системой:

| Проверка | Результат |
|:--|:--|
| 15 модулей, упомянутых в README | ✅ все существуют |
| 14 команд `bookpipe.py` | ✅ все найдены в коде |
| «17 метрик» в `qa.py` | ✅ соответствует docstring (~17) |

**Вывод:** заявления LLM в README **правдивы** — артефакты и функции на месте.
Но «правдиво задокументировано» ≠ «доказано прогоном». KERN честно ставит `N`,
пока нет записи исполнения (команда + код возврата + вывод).
