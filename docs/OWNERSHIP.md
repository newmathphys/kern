## Три независимых механизма закрепления авторства

### 1. Скрытый токен в бинарнике (comptime)

Токен автора (`src/owner.zig`, `OWNER_TOKEN`) **физически впечатан** в секцию
`.rodata` готового бинарника. Он не участвует в логике, но присутствует в теле
файла — удалить, не сломав бинарник, практически невозможно.

**Проверка кражи бинарника:**
```bash
strings zig-out/bin/kernc | grep ed53cd2f1ca8ffb8c9ba3e488f116de4134b9fa3b5afa90e1a040fffde9eefaa
# -> найдено (1 вхождение)
```

| Что | Значение |
|:--|:--|
| Токен (hex) | `ed53cd2f1ca8ffb8c9ba3e488f116de4134b9fa3b5afa90e1a040fffde9eefaa` |
| Токен (base64) | `7VPNLxyo/7jJuj5IjxFt5BNLn6O1r6kOGgQP/96e76o` |

### 2. Ключ-замок (Ed25519, асимметричная подпись)

Публичный ключ автора вшит в код как константа; подпись фразы
«I am the creator of KERN» сделана приватным ключом.

* **Публичный ключ (в коде):** `81e230f74fe0aa81ee011a430a1ae537d4b8f7b603d62a8c6ff2f2d45ddd6ec3`
* **Приватный ключ:** только у автора (НЕ в репозитории).

**Доказательство авторства при споре:** автор публично подписывает ЛЮБУЮ новую
фразу (например, текущую дату и имя оппонента) своим приватным ключом; вшитый
публичный ключ валидирует подпись. Так как приватный ключ есть только у автора,
это математически доказывает авторство.

Проверка в бинарнике:
```bash
zig-out/bin/kernc --version
# Ownership key-lock: ВАЛИДЕН
```

### 3. Git-канарейка (метка в неизменяемой истории)

Файл `formal/.canary` был закоммичен и затем удалён. В актуальном коде его нет,
но он **навсегда остался в истории git**:

```
0ec5a44 AUTHORSHIP CANARY: фиксация авторства Vital Kalinousky (токен в истории git)
858753a Удаление canary-файла (остаётся в неизменяемой истории git как доказательство авторства)
```

Любой, кто скопирует репозиторий и сотрёт имя автора, унесёт эту историю с собой.

## Подпись коммитов

Все коммиты подписаны SSH-ключом Ed25519 (`gpg.format=ssh`):
```
Good "git" signature for Vital Kalinousky with ED25519 key
```
Для зелёной плашки **Verified** на GitHub — загрузить публичный ключ:
`~/.ssh/id_ed25519.pub` (Settings → SSH and GPG keys → New SSH key → **Signing Key**).

## Что НЕ сделано (честно)

* **Аппаратный корень доверия (TPM/SGX/Nitro)** — нет железа. Крипто-конвейер
  реализован (`src/attest.zig`, Ed25519), но анклав не эмулируется.
* **Блокчейн-транзакция** — требует сети и средств; хэш подготовлен.
* **Публикация на GitHub** — требует токена/аутентификации (нет в окружении).
