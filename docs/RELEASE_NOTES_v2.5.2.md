# KERN v2.5.2 — витрина перестала обещать то, чего не может показать

Релиз **исправлений утверждений**, а не новых возможностей. Каждый пункт
найден сверкой с кодом и закрыт гейтом, который способен упасть.

## Исправления

- **#243 `--diff-equiv` обвинял идентичный файл в расхождении.** Команда
считала расхождением всё, кроме «ДОКАЗАНО», а `kernc prove` возвращает один и
тот же код и для «доказано, но пруф-чекер отверг» (`premises_unbound`), и для
«опровергнуто с контрпримером». `make diff-equiv` проходил вакуумно.
Классификация теперь идёт по выводу решателя (`equivalent` / `unverified` /
`diverged` / `unknown` / `tool_error`), плюс положительный контроль:
идентичный файл не обвиняется никогда.
- **#244 витрина обещала интерактив, которого не было**, а в баннере стояло
«200 T / 422 F,N / 409 B» — число, которого нет ни в одном источнике. Числа
заменены законом `join_K(T,F)=B`, стрелки Белнапа развёрнуты по направлению
накопления (`N→F`, `N→T`, `F→B`, `T→B`), добавлены карта потока
доказательства (`docs/kern-proof-flow.svg`), Эго-Линза по РЕАЛЬНОМУ графу
`@import` (радиус 1–2) и матрица фильтров `[+][~][-][=]` по меткам,
пересчитываемым из исходников. Эквивалентность помечена **CLI only**, а не
имитируется в браузере.
- **#245–#247 дыры в стражах чисел**: якорь-комментарий прятал число от
собственного правила (вакуумная проверка), четыре файла содержали якоря,
которые `sync` никогда не обновлял, а документированный пример синтаксиса
принимался за сломанный якорь. Всё три исправлены; `sync --selftest` теперь
создаёт временный файл с якорем и требует, чтобы страж его поймал.

## Конвейер релиза

- GitHub Release собирается **черновик → загрузка ассетов → публикация**:
опубликованный релиз не может существовать без файлов.
- `Release Drafter` больше не создаёт черновик с именем следующего патч-тега:
именно этот черновик перехватывал настоящий релиз тега.
- Release notes берутся по имени тега, а не из жёстко прописанного файла.

## Свидетельства

Числа — данные: `docs/facts.json` + якоря `<!-- fact:key -->`, поэтому README,
сайт и паспорта не могут разойтись.

```bash
make sync-check        # якоря == измеренные факты
make showcase-check    # граф линзы == src/ (3 диверсии в --selftest)
python3 tools/slsa_provenance.py --check
```
