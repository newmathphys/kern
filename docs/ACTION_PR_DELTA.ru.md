# KERN на pull request: дельта вместо отчёта по всему репозиторию

## Почему сменился вопрос

Аудит всего репозитория на каждом pull request отвечает не на тот вопрос. Ревьюер и так
знает, что находки в репозитории есть; ему нужно **что стало хуже В ЭТОМ изменении**.
`--delta BASE HEAD` отвечает ровно на это, а `--sarif` превращает ответ в SARIF 2.1.0,
который GitHub рисует аннотациями прямо в диффе.

## Что сделано

| Часть | Где | Состояние |
|---|---|---|
| composite action (скачать, проверить, аудит, SARIF) | `action.yml` (корень репозитория) | есть с #497 |
| workflow на pull request | `.github/workflows/kern-pr-delta.yml` | добавлен 2026-11-26 |
| готовый к публикации репозиторий действия | `action-repo/` | `gh repo create newmathphys/kern-action --public --source . --push` |

Действие прибито к релизу (`version`, по умолчанию `v2.8.26`), проверяет SHA-256 архива и
подпись Ed25519, запускает `kerna --doctor` и только потом аудирует. Апплаенс несёт свой
Python и свой решатель: раннеру не нужны ни `pip install`, ни Zig, ни `.venv`.

## Измерено, а не предположено

Путь дельты прогнан локально ДО коммита workflow:

```
dA: int f(int *a, int d){ return a[d-3]; }
dB: int f(int *a, int d){ if (d <= 2) return 0; return a[d-3]; }

python3 tools/audit_delta.py /tmp/dA /tmp/dB --sarif /tmp/d.sarif
  поведенческая дельта: изменившихся файлов 1, сравнено 1
  СЕМАНТИЧЕСКОЕ РАСХОЖДЕНИЕ (DIVERGED) — 1: ~ x.c: [DIVERGED] f
  sarif: 5330 байт, version=2.1.0
```

## Чего гейт не утверждает

- **Межпроцедурные выводы не моделируются.** «Новая находка» означает «сработал новый
  детектор», а не «раньше было безопасно». Блокирует только новая находка.
- **Покрытие измерено**: на C распознаётся 51,5 % переполнений размера; `break`/`continue`/
  `goto` моделируются частично. См.
  [`../formal/certification/KNOWN_LIMITATIONS.md`](../formal/certification/KNOWN_LIMITATIONS.md).
- **Дрейф воронки печатается и без новых находок**: рост `skipped` при падении `checked`
  означает «доказано меньше», и молчание здесь было бы нечестным случаем.

## Как посторонний закрывает пилот T7

1. Форкните любой репозиторий или возьмите свой.
2. Добавьте workflow выше — действие само скачает релиз.
3. Откройте pull request. Либо аннотации появятся, либо job упадёт с причиной.
4. Пришлите лог job — этот лог и есть квитанция T7. Ручной вариант на семь минут —
   в [`PILOT_T7.ru.md`](PILOT_T7.ru.md).
