# KERN — ядро проверки истины для ИИ-агентов

> **Отдельный проект.** Не часть `nyuui-core`. `nyuui` может им пользоваться,
> но живёт и развивается самостоятельно.

**Статус:** исследовательский прототип. Физика (mmap, zero-copy) работает и
измерена. Эпистемическая часть (Врата Истины) **имеет подтверждённую
уязвимость** — см. раздел «Что НЕ работает».

---

## 1. Зачем это

KERN — «таможня истины» между ИИ-агентом и реальным кодом. Идея:

1. ИИ генерирует код и **утверждение** («функция безопасна», «тесты прошли»).
2. Утверждение допускается только при **машинной опоре** (прогон, доказательство).
3. Следующему агенту передаётся **компактный пакет**: что доказано, что
   проверять, что открыть, что нельзя трогать.

Математическая основа — **решётка Белнапа-Данна B4**: факт имеет два независимых
бита (подтверждение `p` и опровержение `n`), поэтому «и доказано, и опровергнуто»
(`B`) — это отдельное состояние, а не усреднение.

| код | статус | смысл |
|:--:|:--|:--|
| 0 | **N** | ничего не известно (гипотеза ИИ) |
| 1 | **T** | доказано |
| 2 | **F** | опровергнуто (найден контрпример) |
| 3 | **B** | конфликт: тесты зелёные, но прувер нашёл баг |

## 3. Запуск

```bash
# 1. Компилятор Zig 0.13 (более новые версии НЕ подходят)
uv pip install --python /path/to/venv ziglang==0.13.0

# 2. Эталонный образ
python3 tools/golden_v1_2.py

# 3. Сборка
zig build

# 4. Все тесты ядра
zig build test          # или: zig test src/test_root.zig

# 5. Демонстрация уязвимостей
./zig-out/bin/kern-attack

# 6. CLI
./zig-out/bin/kernc check-integrity tests/fixtures/valid_v1_2.kimg
```

⚠️ **Команда `zig test src/tests/exhaustive_suite.zig` НЕ РАБОТАЕТ** — корнем
модуля становится `src/tests/`, и импорты `../core/...` отвергаются. Нужна
обёртка `src/test_root.zig` (см. `docs/KERN9_SUITE_AUDIT.md`).

## 4. Что **работает** (измерено)

| Свойство | Как проверено |
|:--|:--|
| **Zero-copy чтение через mmap** | срез памяти, копирования нет |
| **0 байт кучи на монтирование** | счётчик аллокатора: `mount +0`, `ls +0`, `cat +0` |
| **Защита записи** | попытка записи в mmap → `SIGSEGV` (код 134) |
| **CONF-13: path traversal** | все 4 отказа: нет `/`, `//`, `.`, `..`, NUL |
| **CONF-15: reserved-байты** | порча байта 95 → `InvalidReservedBytes` |
| **Безопасная арифметика** | offset bomb → `OutOfBoundsOffset` в Debug И ReleaseFast |
| **Алгебра Белнапа** | таблицы join/meet, законы де Моргана полным перебором |
| **Сквозная сверка** | Merkle-корень Zig == корень Python-генератора |

## 5. Что **НЕ работает** (подтверждено, не предположения)

### 🔴 Врата Истины обходятся ОДНИМ БАЙТОМ

`admission_gate.zig` читает вердикт **из полезной нагрузки сертификата**,
то есть из данных, которыми управляет ИИ:

```zig
const magic = payload[0];          // <-- байт от ИИ
if (magic == 0xAA) return .Proved; // <-- ИИ управляет вердиктом
```

Проверено на живом запуске (`kern-attack`): сертификат с одним байтом `0xAA`
даёт `e=1` — код допускается в прод **без единого доказательства**.

**Что нужно:** вердикт обязан приходить ИЗВНЕ (реальный вызов решателя с
тайм-аутом и изоляцией). Пока это не так, «защита от галлюцинаций» не защищает.

### 🔴 KERNFS не находит НИ ОДНОГО файла

Роутер ищет объекты типов `0x0002`/`0x0005` **с путём**, а золотой вектор v1.2
содержит ОДИН объект типа `0x0001` **без пути** (`logical_path_offset = 0xFFFFFFFF`).
Плюс пула строк в образе нет. **Фаза 1 и Фаза 3 несовместимы.**

### 🔴 `report` фабриковал результат

Писал «99% VERIFIED (e=1)» для **любого** файла, не читая образ. Убрано —
теперь пишет честное «образ не анализировался».

### ⚠️ `verify`, `ls`, `cat` — заглушки

`verify` не читает образ (сертификат зашит в код). `ls`/`cat` только печатают
сообщение. Это помечено прямо в коде, а не спрятано.

### ⚠️ «Fake Witness Rejection» работает не так, как заявлено

Отвергаются только свидетели **короче 8 байт**. Строка из 26 байт проходит и
даёт `N` (e=0) — безопасно, но это **не** «отклонение фейка».

## 6. Прочие расхождения со спецификацией

| Заявлено | Факт |
|:--|:--|
| «Zig 0.17.0» | код собирается на **0.13.0** |
| Merkle-корень = **BLAKE3** | и Python, и Zig считают **SHA-256** |
| «исправление reserved до 24 байт в v1.2» | формат **идентичен v1.1** |
| `payload_offset` абсолютный | в v1.2 **относительный** (ломает Фазу 3) |
| `allowed_checkers = 1` разрешает checker 1 | маска `1 << id` → нужен `2` |
| `MerkleRootMismatch` проверяется | объявлен, но **никогда не возвращается** |
| `AccessDenied` при записи | возвращается `FileNotFound` |

## 8. Связь с nyuui-core

`nyuui-core/evidence.py` реализует **родственные** идеи на Python:
типизированную уверенность, журнал решений, пакет агенту (`handoff`),
эпистемическое слияние графов и поручительство человека (Ed25519, статус
`attested` — намеренно **отдельный** от `proven`).

KERN и `nyuui-core` **не связаны кодом** — общая только идея. KERN быстрее
(mmap, zero-copy), `nyuui-core` — рабочий и покрыт тестами.
