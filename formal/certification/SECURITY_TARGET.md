# KERN — Security Target (ST) / Модель политики безопасности

> Назначение: ISO/IEC 15408 (Common Criteria), целевой уровень EAL7.
> Продукт оформляется как **TOE** (Target of Evaluation).
> Модель безопасности: **ADV_SPM.1** (формальная модель политики безопасности).

**Версия:** v1.3 · **Дата:** 2026-10-11 · **TOE:** ядро KERN (kernc, kernx, libkern)

---

## 1. TOE (Target of Evaluation)

| Компонент | Артефакт | Назначение |

## 4. ADV_SPM.1 — Формальная модель политики безопасности

**Состояние:** `S = ⟨Claims, Evidence, Verdicts, Cache⟩`.
**Решение о допуске:** `admit : S → {0,1}`.

### Аксиомы (доказаны в Lean 4)

| ID | Аксиома | Формализация | Файл |
|:--|:--|:--|:--|
| A1 | Решётка Белнапа B₄ полна | таблицы join/meet по полному перебору | `KernAllMath.lean` |
| A2 | Конфликт не «перезаписывается» | `T ⊔ F = B` | `KernAllMath.lean` |
| A3 | Пустое предусловие ≠ доказательство | анти-вакуумный предикат | `KernAllMath.lean` |
| A4 | Обход завершается | тотальность fuel-DFS | `KernDfsTermination.lean` |
| A5 | Несовместимость ⇒ конфликт | `human.max < ai.min ⇒ B` | `KernTalk.lean` |
| A6 | Конвергенция RLAIF | сходимость за конечное число шагов | `KernConvergence.lean` |
| A7 | Zero-copy не искажает данные | изоморфизм отображения | `KernZeroCopy.lean` |
| A8 | Границы типов обязательны | ℤ-свойство ≠ i32-свойство | `KernSemanticGap.lean` |

### Инвариант безопасности (неформально)

> Ни один путь исполнения не приводит к `admit = 1` без вердикта
> `Proved` от доверенного чекера при совпавших дайджестах и разрешённом
> `checker_id`. Все ветви сомнения дают `admit = 0`.

Свидетельство: `src/tests/mcdc_gates_test.zig` (MC/DC-1 … MC/DC-8) —
каждое условие решения проверено на независимое влияние.

## 5. Модель угроз (Threat Model)

| Угроза | Вектор | Контрмера | Статус |
|:--|:--|:--|:--|
| Подмена вердикта ИИ | `payload[0] = 0xAA` | вердикт только от чекера | ✅ закрыто |
| Подмена содержимого образа | правка байта payload | SHA-256 payload | ✅ закрыто |
| Подмена таблицы объектов | правка записи 96 Б | Merkle-корень | ✅ закрыто |
| Переполнение смещений (DoS) | `object_count = 1e9` | безопасная арифметика | ✅ закрыто |
| Path traversal | `../../etc/passwd` | валидация путей | ✅ закрыто |
| Отравление кэша | коллизии хэшей | SHA-256, лавина 50 % | ✅ закрыто |
| Подделка сертификата | чужая подпись | Ed25519 + вшитый ключ | ✅ закрыто |
| Кража кода (присвоение) | копия бинарника | токен в `.rodata`, ключ-замок | ✅ закрыто |
| **Аппаратный сбой памяти** | выдернутый носитель | `siglongjmp`-перехват | ✅ закрыто |
| **Атака на LLVM/сборку** | недетерминированная сборка | воспроизводимость бит-в-бит | ⚠️ частично |

## 6. Границы (вне TOE)

* Аппаратный корень доверия (TPM/SGX) — не используется (нет железа).
* Верификация машинного кода (translation validation) — не выполнена.
* Side-channel / timing-attack на кэш — не исследован.
* Сам решатель Z3 не верифицирован (компенсация — кросс-чек cvc5).
